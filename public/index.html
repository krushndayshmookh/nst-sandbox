NST Sandbox

Your personal Linux server on the NST cluster.

Install

curl -sL https://sandbox.nstsdc.org/install | bash

Quick Start

  1. Create an instance 
    nst-sandbox create my-devbox

    Pick an image, compute tier, and storage interactively.

  2. SSH in 
    nst-sandbox ssh my-devbox
  3. Your site is live at 
    http://my-devbox.nstsdc.org

CLI Commands

CommandDescription
nst-sandbox create [name]Create a new instance
nst-sandbox listList your instances
nst-sandbox ssh <name>SSH into an instance
nst-sandbox info <name>Show instance details
nst-sandbox destroy <name>Delete an instance
nst-sandbox imagesShow available images and tiers
